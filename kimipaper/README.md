# Kimi Paper 工作区

> 目标：撰写一篇 **SAR 舰船目标检测 + Atlas 200I DK（昇腾 Ascend 310B）边缘部署** 的论文，数据集以 SSDD 为主，辅以 HRSID / SRSDD / FUSAR-Ship。

## 选题一句话

**面向昇腾 NPU 的"算法—量化—部署"协同设计的轻量化 SAR 舰船检测方法**：把 NPU 亲和性前置到网络设计中，配合蒸馏 + 免重训练闭式剪枝 + 伪标签数据扩充，在 Atlas 200I DK 上给出完整实测链路与端到端指标。

## 为什么这个选题成立（核心依据）

1. **领域空白**：检索 2024–2026 文献，"SAR 舰船检测 + Ascend 310B"组合**基本无已发表工作**；现有轻量 SAR 检测论文全部以 GPU FPS 为准，部署类论文（如信号处理 2024）是 GPU + TensorRT 平台。
2. **平台真实痛点**：310B 上 NMS 算子不支持、INT8 量化掉点（域外校准可致 ~25% mAP 损失）、FP32 需强制 FP16、CPU 极弱（4 核 1.0GHz）——这些"坑"从未在 SAR 场景被系统研究，本身就是论文素材。
3. **手头资源可直接复用**（见 `../background/`）：
   - `YOLO-Master-main`：框架基座（Ultralytics → ONNX → Ascend OM 一键导出链、Sparse SAHI、CW-NMS、LoRA、MoE 剪枝）
   - `NuWa-main`：免重训练闭式剪枝（SVD 能量降维 / 补偿 / 最小二乘）→ 多档模型快速派生
   - `Fast-FoundationStereo`：教师-学生特征蒸馏范式 + 伪标签数据扩充管线
   - `2603.28149v1.pdf`（BLANKSKIP）：空场景 early-exit 门控（SAR 大幅面背景占比高，契合）
   - `2604.17087v1.pdf`（EvoComp）：GHM loss（前景/背景极度不平衡）

## 建议的 3 条贡献（论文 Introduction 末尾按此写）

1. **提出一种 NPU 亲和的轻量化 SAR 舰船检测器 ASC-SAR**：以算子白名单与 AIPP 预处理下沉为约束设计骨干/Neck/检测头，小目标 P2 分支与稀疏切片输入级加速，填补"SAR + Ascend 310B"部署空白。
2. **提出部署感知的压缩管线**：教师特征蒸馏 + NuWa 式免重训练闭式剪枝，按 Atlas 200I DK 算力/内存档快速派生多档模型；QAT 与量化敏感性分析保证 INT8 近似无损。
3. **构建伪标签扩充与系统评测协议**：多模型一致性过滤自动标注未标注 SAR 图像；在 SSDD/HRSID/SRSDD/FUSAR-Ship 杂波切片上给出 mAP/FPS/功耗/内存的端到端实测与跨传感器泛化评测。
