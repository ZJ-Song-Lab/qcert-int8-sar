## 二、摘要草稿（先按 200 词写，后续随实验填数）

合成孔径雷达（SAR）舰船检测在海上监视中具有全天时全天候优势，但现有轻量化方法均以 GPU 为部署假设，面向昇腾 Ascend 310B 等 NPU 边缘平台的系统研究仍属空白，模型转换中的算子缺失、量化掉点与弱 CPU 预处理瓶颈缺乏针对性设计。本文提出 ASC-SAR，一种算法—量化—部署协同设计的轻量化 SAR 舰船检测器。在网络层面，以 NPU 算子白名单为约束设计部署友好骨干与 Neck，引入 P2 高分辨率小目标分支与 objectness 引导的稀疏切片，缓解大幅面图像中小目标漏检与算力浪费；在压缩层面，采用教师特征蒸馏与免重训练闭式剪枝，按设备算力档快速派生多档模型，并以量化感知训练与敏感层混合精度抑制 INT8 掉点；在数据层面，构建多模型一致性过滤的伪标签管线扩充 SAR 训练数据。在 SSDD、HRSID、SRSDD 与 FUSAR-Ship 杂波切片上，ASC-SAR 在 Atlas 200I DK 上取得 XX FPS / XX W 的端到端性能，INT8 精度损失 < X 个点，跨传感器评测验证了域鲁棒性。

**关键词**：SAR 舰船检测；边缘部署；昇腾 NPU；模型压缩；量化感知训练；小目标检测

## 三、完整章节大纲

### 1. 引言（Introduction）

- **1.1 背景与动机**
  - SAR 成像全天时全天候，舰船检测是海洋监视核心任务；岸边/舰载/无人平台的边缘实时处理需求增长。
  - 边缘 NPU（昇腾 Atlas 200I DK，310B，8 TOPS INT8 / 4GB）成为国产边缘 AI 主流载体，但其工具链（ONNX→ATC→OM→ACL）与 GPU/TensorRT 差异巨大。
  - **痛点陈述（本文的问题来源）**：
    1. 现有轻量 SAR 检测器（AC-YOLO、DS-YOLO 等）以 GPU FPS 为指标，结构与算子未考虑 NPU 白名单；
    2. NMS 等算子在 310B 上不受支持，INT8 量化在 SAR 小目标上掉点明显；
    3. SAR 标注稀缺，SSDD 仅 1160 张，限制轻量模型训练上限。
  - 引出"算法—量化—部署协同设计"的必要性。

### 3. 方法（Method）

- **3.1 总体框架与 NPU 亲和设计原则**
  - 图 1：ASC-SAR 总体架构（输入稀疏切片 → 部署友好骨干 → P2-P4 Neck → 三尺度头 → CPU 轻量后处理）。
  - 设计原则 P1–P4：
    - P1 算子白名单：只用 Conv/BN/SiLU/Add/Concat/Resize 等 ATC 友好算子，规避 grid_sample、动态 shape 等；
    - P2 预处理下沉：归一化/均衡化走 AIPP，释放弱 CPU；
    - P3 后处理最简：导出无 NMS 图，CPU 端轻量 NMS（可融合 CW-NMS 加权思路）；
    - P4 定点友好：减少 sigmoid/exp 敏感点，关键层保留 FP16 混合精度通道。
- **3.2 部署友好骨干与 Neck**
  - Ghost/深度可分离卷积重参数化模块（训练多分支 → 推理单路，兼容 ATC 静态图）；
  - 坐标注意力（轻量、无复杂 reshape）强化小目标；
  - 三尺度 + P2 浅层高分辨率检测头（SSDD 小舰船占比高）。
- **3.3 输入级加速：objectness 引导的稀疏切片**
  - 借鉴 Sparse SAHI：全局 objectness mask 引导滑窗，跳过低于阈值的切片；
  - 与 early-exit 门控（BLANKSKIP 思路）的对比与选择：切片级门控更适合大幅面 SAR。
- **3.4 部署感知压缩管线**
  - 3.4.1 教师特征蒸馏：YOLO-L/x 教师 → ASC-SAR 学生，多级特征金字塔 MSE 蒸馏（借鉴 Fast-FoundationStereo）；
  - 3.4.2 免重训练闭式剪枝多档派生：SVD 能量降维 + 激活校准补偿/最小二乘重建（借鉴 NuWa OFP），按 310B 不同内存/算力档一键派生 S/M/L 三档模型；
  - 3.4.3 量化感知训练：QAT + per-channel + 敏感层（P2 头、sigmoid 前）混合精度/skip_layers 配置；GHM loss 缓解前景背景不平衡。
- **3.5 伪标签数据扩充管线**
  - 教师 + 多模型（不同骨干）一致性过滤（类比 FFS 法线一致性 mask 思路：IoU 投票 + 置信度阈值）；
  - 用其自动标注 Sentinel-1 未标注切片，扩充 SSDD 训练集（报告扩充前后曲线）。

### 4. 实验（Experiments）

- **4.1 数据集与评测协议**
  - 主基准 SSDD（1160 张/2456 舰，官方 BBox/RBox 标注，尾号 1/9 测试协议）；HRSID 验证高分辨率泛化；SRSDD 验证近岸密集场景；FUSAR-Ship 杂波切片做虚警/鲁棒性评测。
  - 指标：mAP@0.5、mAP@0.5:0.95、参数量、FLOPs、模型大小；部署端 FPS（端到端与纯推理分开）、功耗（W）、内存占用；INT8 相对 FP16 掉点。
- **4.2 实现细节**：训练配置（数据增强、epoch、lr）、ATC 转换参数（soc_version=Ascend310B1/B4、input_format、AIPP 配置）、AMCT 量化配置。
- **4.3 与 SOTA 对比**（表 2–3）
  - 双平台对比是本论文特色：同模型在 GPU+TensorRT 与 Atlas 200I DK 上同时报告，凸显平台差异；
  - 对比方法：YOLOv8n/v11n、AC-YOLO、DS-YOLO、轻量注意力 YOLOv11n 变体（2025 ICCK）等。
- **4.4 消融实验**（表 4，SSDD 为主）
  - 基线 → +P2 头 → +坐标注意力 → +稀疏切片 → +蒸馏 → +闭式剪枝 → +QAT，逐模块消融；
  - 切片阈值 λ、蒸馏权重、剪枝率、量化配置各 1 个超参敏感性图。
- **4.5 量化与部署实测分析**（本文独有卖点）
  - PTQ vs QAT 掉点曲线；域外校准 vs SAR 域内校准对比（复现"25% 掉点"现象并给出对策）；
  - 端到端延迟分解（AIPP/推理/CPU 后处理占比）、功耗-精度权衡曲线（多档模型 S/M/L 的 Pareto 前沿）。
- **4.6 跨传感器与杂波鲁棒性**
  - SSDD 三传感器（RadarSat-2/TerraSAR-X/Sentinel-1）分组评测；HRSID→SSDD 跨数据集直接迁移；FUSAR-Ship 杂波切片虚警率（FPPI）。
- **4.7 可视化**：复杂海杂波、近岸密集、小目标簇的典型检测结果对比图。

### 5. 讨论（Discussion）
