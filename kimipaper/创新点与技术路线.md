## 四、实验设计明细

### 4.1 基准与协议

- **SSDD**（主）：1160 张 / 2456 舰；官方划分（尾号 1/9 测试）；mAP@0.5 主指标。
- **HRSID**：高分辨率泛化（5604 张，实例分割转框）。
- **SRSDD-v1.0**：近岸密集 + 旋转框场景（可只做水平框子集评测）。
- **FUSAR-Ship**：杂波切片虚警率（FPPI）与鲁棒性。
- 数据受限时用 SARDet-100K 舰船子集做预训练（可选）。

### 4.2 对比方法

- 轻量通用：YOLOv8n、YOLOv11n、YOLOv12n（GPU + Atlas 双平台）。
- SAR 专用轻量：AC-YOLO、DS-YOLO、ICCK 2025 自适应空间融合 YOLOv11n。
- 压缩路线：BN 剪枝基线、普通 PTQ INT8。

### 4.4 量化专项（卖点实验）

1. PTQ（域外校准 vs SAR 域内校准）掉点对比——复现"25% 掉点"并归因；
2. QAT vs PTQ；per-channel vs per-tensor；敏感层混合精度/skip_layers；
3. 小目标尺寸分组（<16px / 16–32px / >32px）下的 INT8 敏感性；
4. FP16 vs INT8 的 FPS/功耗对比（310B 上 INT8 算力翻倍，收益可观）。

### 4.5 部署实测

- 端到端延迟分解：AIPP 预处理 / 推理 / CPU 后处理三段占比；
- 功耗：满载 W、典型场景 W（可用 Atlas 自带功耗接口或功率计）；
- 内存：OM 模型 + 运行时峰值；
- 多档模型 S/M/L 精度-功耗 Pareto 前沿。

### 4.6 鲁棒性（扩展）

- SSDD 传感器分组（RadarSat-2 / TerraSAR-X / Sentinel-1）直接评测；
- HRSID→SSDD 零样本迁移 mAP；
- FUSAR-Ship 杂波切片 FPPI@0.5；
- （可选 E）INT8 与 FP16 的跨域掉点差——支撑"量化×域偏移"讨论。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 闭式剪枝迁移到 CNN 检测器效果不佳 | 退路：改 BN 缩放因子剪枝 + 短程重训练，NuWa 式仅作消融对比 |
| ATC 转换部分新结构失败 | 备选模块池（RepGhost/RepVGG 块、SE 注意力均为白名单算子），阶段 0 先验证 |
| QAT 掉点超预期 | 混合精度 + 敏感层 FP16 保底，报告边界即可（本身就是贡献点） |
| 昇腾开发板内存/算力不足 | 固定 640×640、batch=1、滑窗切片，早已纳入设计 |
| 伪标签质量差 | 提高投票阈值 + 人工抽检 200 张报告精度 |
