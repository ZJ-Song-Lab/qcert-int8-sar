## 四、LaTeX 构建管线（paper\latex\）

**build_paper.py** 四步（`python build_paper.py all`，在 latex\ 下）：
1. `sync`：把 11_实验章节.md 整章同步进 20_论文全文_插图版.md 的 §4（锚点 `# 4 实验（Experiments）`）
2. `body`：从插图版 "# 1 " 行起剥编号生成 body.md
3. `pandoc`：pandoc body.md → body.tex（--top-level-division=section）
4. `post`：caption→caption*（正文手动引用 Fig.N）、剥 label、剥 figs/ 前缀

**编译**（需两次以稳定目录）：

```
cd "neural networks\paper\latex"
python build_paper.py all
xelatex -interaction=nonstopmode main_nn.tex
xelatex -interaction=nonstopmode main_nn.tex
Copy-Item main_nn.pdf "..\QCert论文_NeuralNetworks格式.pdf"
```

- main_nn.tex = Neural Networks 版（\journal{Neural Networks}，preprint/12pt，含 Highlights 5 条 + 中英摘要）；main.tex = ASC 版。
- 环境：pandoc 3.11 + MiKTeX XeTeX 4.16；中文走 ctex（SimSun），特殊符号走 Segoe UI Symbol（⇒ − ✓ ✗ ⚠ 等）。
- 当前编译结果：86 页、0 缺图、0 LaTeX Error、95 处 Overfull（URL/长表，外观性）。
- 投稿前需填写 main_nn.tex 中作者/单位占位符。
