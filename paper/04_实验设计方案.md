> 目标：为 C1（误差界与搬运）/ C2（整数判决层）/ C3（只有这块板能做的实验）提供**可证伪**的证据。
> 纪律：① **先证伪再证明**——E0 是存在性硬门，不过则选题不成立；② 口径先行，跑数前把表建好；③ 每个数字带 CI 或跨场景标准差；④ 所有"只有板上能做"的实验，必须在文中写明"换到 GPU FP16 上该实验无意义"的理由。

## 0. 实验总原则

1. **主指标换了**：不是 mAP，也不是 P_d，而是 **P_fa 的精度不变性**——
   `R = P_fa(INT8) / P_fa(FP32)`，报告 `|log10 R|` 与跨海况最大值。
2. **mAP 只作兼容性对照**，用来证明"我们的方法没有牺牲检测"和"mAP 看不见这个问题"。
3. **每个结论都要有解析预测 vs 实测的对照**：Prop.2 给出 `|ΔP_fa| ≤ L·δ`，δ 由 scale 表算出 → 实测落在界内才算通过。这是本文区别于"工程调参"的关键。
4. **单板纪律**：只有一块 Atlas 200I DK，跨实现对照用 {同 `.om` 重复运行, ONNX-Runtime INT8, FP32} 三点，论文中显式标注平台差异，不冒充多板实测。

## 2. 指标定义（写进论文 4.1 节，逐字固定）

### 2.1 契约类（主指标）

- `P_fa^pixel = #{u ∈ Ω : ŷ(u)=1} / |Ω|`，逐场景算，跨场景报 mean ± std 与 min/max。
- `P(≥1 FA per scene)`：逐场景至少一个虚警的比例；另报**每场景虚警数**的 median / P90 / max。
- **精度不变性** `R = P_fa^{INT8} / P_fa^{FP32}`（同一测试集、同一标定流程、同一 α），报 `|log10 R|`。
- **偏离度** `|log10(P_fa^{INT8} / α)|`，跨海况取最大值——"契约是否还守"的一句话表述。

### 2.2 量化诊断类（本文独有）

- **逐层饱和率** `sat_l = #{a_q = 127 或 −128} / #elements`，按层、按海况报；并统计分数场最高 1% 内的**并列数**（同一整数值的样本数）——这是"排序塌陷"的直接证据。
- **实测量化步长** `ε_σ = Δ_σ/(2σ)`：`Δ_σ` 从 AMCT 产物读出，σ 取该层统计中位数；报分布而非单值。
- **验收误差** `|e_s|`：INT8 与 FP32 在同一位置的分数差，统计 P99。
- **判决不一致率**：INT8 与 FP32 判决逐位置不一致的比例；以及"不一致位置中 GT 框内占比"（判断代价是虚警还是漏检）。

### 2.3 检测类（兼容性）

- `P_d@P_fa`：扫 α 序列得 (P_fa, P_d) 曲线，插值读 `P_fa = 1e-3 / 1e-4` 处的 P_d。
- `mAP50 / mAP50-95`：兼容性对照，**不作为结论**。
- `d'`：`(mean(z|H1) − mean(z|H0)) / std(z|H0)`，用于解释 C2。

### 2.4 系统类（Atlas 200I DK A2）

- `T_model`（ACL，batch=1，预热 50 / 测 500）、`T_e2e`（预处理→NPU→整数判决→NMS）；
- **P99 与 P99/mean**；每场景候选数分布（进 NMS 前）；
- **J/艘**（板级功率 × 时间 / 检出船数）与 **J/帧**；
- 内存（AI Core + 进程 RSS）、板级功率、芯片温度、是否降频、CPU 占用（4×Taishan @1.0 GHz，用来证明 host 已退出回路）。

### 2.5 统计纪律

- 训练类：3 个种子，mean ± std。
- P_fa 类：场景级 bootstrap（1000 次）→ 95% CI；跨桶比较用配对检验。
- 报 `n` 与 `n_eff`（块抽样后的有效独立样本数），并写明 `α ≥ 1/n` 的可达下界。

## 3. E0：存在性门槛（Fig.1，**第一个做**）

**目的**：证明"同一模型、同一输入，量化让 mAP 几乎不动，但让 P_fa 变数倍"。

**为什么它能先做**：这一步**不需要**零模型 `h0`，也不需要任何新训练——只需要 `asc-sar` 已有的 FP16/INT8 双链路 + 一个分数场 dump 接口。它是全项目成本最低、信息量最大的实验。

**协议**：
1. 用 `asc-sar` 已训好的 YOLO11n 基线（SSDD），导出 FP32 ONNX；
2. 板上编 `FP16 .om` 与 `INT8 .om`（AMCT 校准集按 1.3 分层）；
3. 对 SSDD test 的每个场景 dump 分数场（FP16 输出 vs INT8 反量化输出）；
4. 在**同一杂波位置集合 Ω** 上，用**同一 α**（1e-3、1e-4）分别标定 `λ` 与计算实测 P_fa；
5. 同时算 mAP50；
6. 按 1.2 的三桶分组画 Fig.1：左图 P_fa（对数轴），右图 mAP50。

**Go / No-Go**：
- **Go**：`R = P_fa^{INT8}/P_fa^{FP32} ≥ 1.5`，且 `|ΔmAP50| < 1` 点；
- **边际**：`1.2 ≤ R < 1.5` → 保留选题，但主张降级为"证明 PTQ 对误警率基本安全"（投 GRSL/Remote Sensing，见第 10 节）；
- **No-Go**：`R < 1.2` 且 mAP 也几乎不变 → 量化误差太小，**改走饱和主线**：构造高杂波压测集（见 §5），用 E2 的饱和率与并列数立论。

## 4. E1：Prop.2 的数值验证（理论可信度的地基，**Fig.4**）

**目的**：证明误差界 `|P_fa(ẑ) − P_fa(z)| ≤ L·δ` 不是空话——（i）在合成分布上界成立；（ii）在真实无船场景上，实测漂移量与 δ 预测同阶。

### 4.1 合成实验（可控 ground truth）
- 零分布：高斯、Student-t(ν=3)、**空间相关高斯随机场**（ℓ = 1/4/8/16 px）；
- 人为注入量化误差：按 `Δ_s, Δ_μ, Δ_σ` 量化 s/μ/σ 后重算 z；
- 扫 `ε_σ ∈ {1%, 2%, 5%, 10%, 20%}`，每个设置 10⁵ 次重复；
- 对比四条曲线：**实测 Δln P_fa**、**Prop.2 的上界**、**一阶近似 `z²·ε_σ`**、**mAP 代理量（AUROC 变化）**。

**验收**：实测值始终在 Prop.2 界内；`z²·ε_σ` 在 `ε_σ ≤ 10%` 时与实测偏差 < 20%；同时给出"AUROC 变化 < 0.2 个点"——这就是 Fig.1 的理论版。

## 5. E2：饱和审计（**只有定点板能做**）

**目的**：把"饱和 → 排序塌陷 → 分位数失效"这条机制做成可观测量，并关联到检测代价。

**协议**：
1. 在 `.om` 各层输出上取 `a_q`，统计 `sat_l`（按层 × 按海况）；
2. 对分数场取最高 1% 的样本，统计**并列数**（同一整数值出现的次数）与"饱和位置数"；
3. 构造**高杂波压测集**：从 HRSID 近岸 + 强海况子集中挑 100 张，再人工放大对比度（3 档），逼出饱和；
4. 关联：`sat_l` 与 E0 的 P_fa 漂移、以及漏检率的关系（散点 + 相关系数）。

**Go 判据**：压测集上饱和率随对比度**单调上升**，且与 `R` 正相关（Spearman ρ > 0.5）。若不成立，说明该模型的 range 校准已足够保守，饱和机制不是主导项——此时主线回到分母机制（E4），叙事需相应调整（如实写）。

|---|---|---|---|---|---|---|

>    （这反而加强了整数域判决契约的叙事）；
> 2. 饱和的真实发生位置是 **Neck 的 int8 特征层**（每个 Conv 前的 AscendQuant 均

> 3. 并列数机制不变且更强：int8 特征饱和 → 邻近位置特征向量趋同 → int32 分数码
>    并列 → 排序塌陷。`tie_stats` 对 int32 码同样适用（代码已验证）。

## 6. E3：三实现判决差异与 bit-exact 复现（C2 的存在性，**Fig.7 + Table 2**）

**目的**：把 A1（同设备可复现）与 A2（跨实现不一致）从假设变成实测。

**协议**：
- 实现 A：`INT8 .om` 在板上的输出，**重复 1000 次**（同一输入）→ 统计逐 bit 一致率（期望 1000/1000）；
- 实现 B：`ONNX-Runtime INT8`（x86 主机，同一量化配置）→ 与 A 的分数场/判决逐位置比对；
- 实现 C：FP32 ONNX（x86）→ 参照系；
- 对每条实现，用各自分数场重新标定 λ，并计算"若沿用 FP32 的 λ"时的 P_fa。

**验收**：A 的重复一致率 100%（A1 成立）；B 与 A 的判决不一致率 > 0 且与 Prop.2 的界一致（A2 成立，且被界住）；"沿用 FP32 λ"的 P_fa 漂移显著大于"重标定"的漂移（C2 的价值）。

## 7. E4：σ 量化粒度消融（验证可证伪预言 P1）

**目的**：证明分母机制是主导项，且"σ 的量化粒度"是可控的旋钮。

## 8. E5：阈值搬运（免数据跨配置/跨传感器）

**目的**：证明 `λ_int` 的换算规则能让"旧标定"在新量化配置/新传感器上仍然守约，**不需要重跑标定集**。

**四个设置**：
1. **同设备、改量化配置**：AMCT 校准集 A → 校准集 B（不同海况比例），用 scale 比换算出 `λ_int`；
2. **同设备、FP16 → INT8**：把 FP16 下标的 λ 搬到 INT8；
3. **跨传感器**：SSDD Sentinel-1 → SAR-Ship-Dataset GF-3（同一模型，不重训）；
4. **上界对照**：在目标域**重跑**标定（64 张无标注图）。

**验收**：设置 1–3 的实测 P_fa 与 α 的偏离 `|log10|` ≤ 设置 4 的 1.5 倍以内；且三者都优于"直接沿用旧 λ、不换算"。

> 这一节是"只有这类板子能做"的最强证据：**GPU 的 scale 不是编译期常量，因此搬运规则在 GPU 上无处定义。**

## 13. 预注册目标与降级方案

### 13.1 预注册（写作前锁定）

1. `R = P_fa^{INT8}/P_fa^{FP32} ≥ 1.5`，且 `|ΔmAP50| < 1` 点（E0）；
2. 实测 P_fa 跨海况最大偏离 ≤ 3×；
3. `P_d@P_fa=1e-3` 相对最强复现基线 ≥ −1.5 点；
4. `P99/mean` 相对全局阈值 ≤ 1/2；判决层 < 3 ms；
5. 配置 2/3 的 `Δln P_fa` 相对配置 1 下降 ≥ 5×（P1）；
6. 搬运后 P_fa 偏离 ≤ 重标定上界的 1.5 倍。

### 13.2 降级方案（按优先级）

| 触发条件 | 降级动作 | 目标 venue |
|---|---|---|
| E0 的 R 在 1.2–1.5 | 主张改为"证明 PTQ 对误警率基本安全 + 给出界"，去掉"数倍漂移"表述 | GRSL / Remote Sensing |
| E0 的 R < 1.2 | **改走饱和主线**：E2 压测集 + 并列数 + range 校准策略成为主结果 | JSTARS |
| E2 饱和不随压测上升 | 主线回到分母机制（E4），删除饱和叙事 | JSTARS |
| E4 的 P1 不成立 | 报告实测 ε_σ 的主导来源，修正 Prop.2 的假设，理论贡献降级为"经验界" | TGRS 转 JSTARS |
| 整数判决层 > 3 ms | 退到 host 整数代码（仍 bit-exact，多一次 DMA），并如实报告 | 任意 |
| 无第二块板 | 三点对照（同 .om 重复 / ORT INT8 / FP32），不冒充多板 | 任意 |
