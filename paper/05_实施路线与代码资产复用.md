## 3. 里程碑（M0→M7）

### M0 环境核对与分数场打通（1–2 天量级）

- `npu-smi` 确认 `soc_version` 与 CANN 版本；
- 复用 `asc-sar` 已有权重（或 `train.py` 重训 YOLO11n，150 epoch，mAP50 应落 96–99）；
- 编 FP16 / INT8 两个 `.om`；
- 实现模块 1（dump 分数场）与模块 2（scale 表），确认**逐层 scale 可读**。

**验收（硬门）**：`Δ_s, z_s` 与输出层 range 能被脚本读出来并打印；同一个 `.om` 重复 1000 次 dump 的分数场**逐 bit 一致**（A1 成立）。若 scale 读不出，A3 不成立 → 整个 C1 需换实现路径（例如直接从 `.om` 的量化节点属性解析），这不是小事，必须在 M0 解决。

### M1 存在性门槛 E0（**Go / No-Go**）

- 对 SSDD test 全部场景 dump FP16 与 INT8 的分数场；
- 用模块 7 在**同一 Ω、同一 α** 下分别标定 λ、算 P_fa 与 mAP50；
- 出 Fig.1（左 P_fa 对数轴 / 右 mAP50，三海况桶）。

**验收（硬门）**：`R = P_fa^{INT8}/P_fa^{FP16} ≥ 1.5` 且 `|ΔmAP50| < 1` 点。
- 通过 → 进 M2；
- 1.2–1.5 → 降级方案（04 文档 13.2）；
- < 1.2 → **改走饱和主线**（直接进 M3 的压测集），或按用户意愿换路线。

> **这一步只用已有代码 + 约 200 行新代码，就能判定论文成败。**

### M2 整数判决层（C2）

- 模块 3、4：整数分位数 + 交叉相乘判决；
- 与 FP32 判决做逐位置等价性验证（应 >99.9% 一致，差异仅来自整数截断）；
- 测判决层耗时（目标 <3 ms）。

**验收**：等价率 >99.9%；判决层 <3 ms；直方图桶数 B 的 α 误差 <1e-4。

### M3 理论验证与饱和审计（C1 前半 + C3-E2）

- 模块 5：饱和审计；
- 04 文档 E1（合成 + 真实无船）与 E2（压测集）；
- 产出一张"解析界 vs 实测漂移"的校准图——**这是把论文从工程抬到科学的那张图**。

**验收**：实测漂移落在 Prop.2 界内；压测集饱和率随对比度单调上升且与 R 正相关（若否，如实调整叙事）。

### M4 零模型训练（开始花训练成本）

- 阶段 1：H1（YOLO11n）冻结；
- 阶段 2：杂波池（10⁴–10⁵ 片）上训 `h0`，`L_H0`，`s_raw` stop-grad；
- 消融：仅 μ / μ+σ / μ+σ+c；对比 M1 的无零模型版本（直接用 s 的分位数）。

**验收**：`P_d@P_fa=1e-3` 优于无零模型版本 ≥1 点；`R` 不劣化。

> 若 M1 已经过门，而 M4 的增益不明显，论文仍然成立——此时零模型只是"更细的被量化对象"，主线是算术而非统计。**这是 v3 的抗风险设计**。

### M5 σ 量化粒度（C1 的 P1 预言）

- 模块 2 支持读取不同 σ 参数化下的 scale；
- 四个配置：线性·逐张量 / 对数域 / 逐通道 / σ 层回退 FP16；
- 测 ε_σ 与 Δln P_fa。

**验收**：配置 2/3 的 Δln P_fa 相对配置 1 下降 ≥5×。这是全文唯一的"可证伪预言"，必须正面回答。

### M6 阈值搬运（C1 后半）

- 模块 6；
- 三设置：同设备换校准集、FP16→INT8、跨传感器（SSDD S1 → SAR-Ship GF-3）；
- 上界对照：目标域 64 张无标注重标定。

**验收**：搬运后 P_fa 偏离 ≤ 重标定上界的 1.5 倍。

### M7 系统与成稿（C3）

- 模块 8：40 min 热稳态；
- E7 部署矩阵（{FP16,INT8}×{全局,QCert}）+ 混合负载 + J/艘；
- 出 Fig.1 / Fig.3 / Fig.5 三张核心图，按 `01_论文大纲.md` 填章节；
- 用 `03` 文档 C1 的九条话术内审；补全所有"待复核"引用。

**验收**：投稿包（TGRS / JSTARS 格式）。

| 改动点 | 文件 | 具体做法 | 风险 |
|---|---|---|---|
| dump 分数场 | `deploy/acl_infer.py` | 在 decode 之前保存原始输出张量；INT8 模型需按输出层 scale 反量化，或**直接保存 int8 原值 + scale**（后者更符合 v3 的"整数域"叙事，建议两者都存） | 输出层 scale 的获取方式随 CANN 版本变 |
| 绕过 NMS | `deploy/postprocess.py` | 新增 `decode_dense()`：不做置信度过滤与 NMS，返回 `(H,W)` 级分数图（对每个网格取 `max_c sigmoid(cls)`） | 多尺度头需上采样对齐，注意 letterbox 反向映射 |
| 逐层饱和统计 | `deploy/acl_infer.py` | 需 dump 中间层 → 用 ATC 的 `--output_type` 或分图导出；若麻烦，退化为只审计"分数场"与"Neck 末层"两层 | 全层 dump 可能需要拆图，成本高；**先做两层** |
| 整数判决 | `qcert/decision.py` | 全部整数运算，`int64` 中间量；`σ_min` 防止除零（在整数域即防 `σ_q=0`） | 若 σ 层被量化到 0，需要 `σ_min` 兜底 |
| 阈值搬运 | `qcert/transfer.py` | 只依赖两份 scale 表，不碰数据；写成纯函数便于单测 | scale 的"旧/新"对应关系要写清 |

| 量化配置 | `deploy/amct_ptq.py` | 加 `--no-fallback`（全 INT8）与 `--stratified`（三海况分层校准） | AMCT 版本差异 |

**明确不做**：不改 backbone、不加注意力、不做 NAS、不做蒸馏主导方案、不做 QAT。

## 5. 审稿人问题清单（v3 答辩口径）

1. **"这不就是普通 PTQ / 量化部署吗？"** → PTQ 的验收口径是 mAP。我们给出"mAP 差 <1 点、P_fa 差数倍"的实测，并在理论上说明为什么（尾分位 vs 全排序积分）。
2. **"Is INT8 Portable? 已经说过 INT8 不可移植。"** → 他们测量现象，我们给出误警率的解析界、整数域判决规则、以及免数据的阈值搬运。
3. **"把板子换成 Jetson，论文还成立吗？"** → 不成立（设计如此）：FP16 无饱和、无编译期固定 scale 表、无可读逐层仿射参数。
4. **"保证依赖可交换性吗？"** → 是，且用块抽样 + n/n_eff + 相关场实验量化偏差。
5. **"α 能到多小？"** → `α ≥ 1/n`；块抽样后 n≈2–5k，实际下界 1e-3~1e-4。
6. **"这不就是 CFAR 吗？"** → 继承契约，丢弃"像素幅度分布 + 浮点算术"两个假设。
7. **"这不就是 CFARnet 吗？"** → 软惩罚 / 固定阈值 / FP32 / 无界 / 无板级实测，五点全不同。
8. **"这不就是 conformal 吗？"** → 保证对象（误警 vs 覆盖）、标签需求（零标注 vs 需标注）、**保证作用的模型（整数部署模型 vs 浮点校准模型）**。
9. **"量化误差这么小，问题真实吗？"** → 给 `Δln P_fa ≈ z²·ε_σ` 的数值表，并用 AMCT 实测 ε_σ 代入。
10. **"只有一块板，怎么证明可移植性？"** → 三点对照（同 .om 重复 / ORT INT8 / FP32），且明说平台差异。
11. **"为什么只在 SSDD 上？"** → SSDD 主实验 + HRSID 压测 + SAR-Ship 跨传感器；且正因 SSDD 的 mAP 已饱和，才适合演示"指标失效"。
12. **"整数分位数会不会更慢？"** → 直方图 O(n) 单遍、不排序；实测 <3 ms，且随候选数不线性增长。
13. **"降频会不会破坏契约？"** → 整数算术不变 ⇒ 输出不变 ⇒ 契约不变；热稳态实验正面回答（E6）。
14. **"这算创新还是工程？"** → 删掉 Prop.2 的界，方法就退化为"INT8 版 CFAR"；删掉整数判决层，P_fa 漂移；两者都是可测的（02 文档 §7 自检清单）。

## 8. 依赖关系（只列顺序，不给工期）

```
M0 环境核对 + 分数场/scale 打通          ← 硬门（A1、A3）
   └─> M1 E0 存在性（Fig.1）             ← 硬门（R ≥ 1.5）
          ├─> M2 整数判决层（C2）
          ├─> M3 理论验证 + 饱和审计（C1 前半 / C3-E2）
          ├─> M4 零模型训练（可选增强）
          │      └─> M5 σ 量化粒度（P1）
          └─> M6 阈值搬运（C1 后半）
                 └─> 与 M5 汇合 ─> M7 热稳态 + 系统测量 + 成稿
```

**关键路径**：M0 → M1。这两步不做完，不要投入 M4 的训练成本。
