## 2. 指标定义（论文 4.1 节逐字固定）

- `P_fa^pixel = #{u∈Ω : ŷ(u)=1}/|Ω|`，逐场景算，跨场景报 mean±std。
- **精度不变性** `R = P_fa(INT8)/P_fa(FP32)`，报 `|log10 R|`。
- **偏离度** `|log10(P_fa/α)|`，跨海况取 max。
- 逐层饱和率 `sat_l`、实测量化步长 `ε_σ = Δ_σ/(2σ)`（分布而非单值）、判决不一致率。
- 检测兼容性：`P_d@P_fa`、mAP50/95（仅对照，不作结论）。
- 系统：`T_model`、`T_e2e`、P99、P99/mean、候选数分布、J/艘、功率、温度。

## 3. 逐实验结果

### E0 — 存在性门槛（Fig.1）｜真实板级 dump

**协议**：同一 SSDD test 232 图，同一 Ω、同一 α=1e-3，分别用 FP16 OM 与 INT8 OM dump 分数场，各标定 λ 并测 P_fa，同时算 mAP50。

| 指标 | 值 |
|---|---|
| n_scenes / n_meas | 232 / 949703 |
| P_fa (FP16) | 1.60251e-3 |
| P_fa (INT8) | 1.55307e-3 |
| **R** | **0.969149**（CI95 [0.90137, 1.03336]，median 1.0） |
| dev_from_alpha (FP16 / INT8) | 0.3313 / 0.3454 |
| mAP50 (FP16→INT8) | 98.27 → 97.98（Δ = −0.29 pt） |
| pass_R / pass_map | False / True |
| **verdict** | **NO-GO（R 点判据）** |

**解读**：R 点估计 0.969 略低于 1，但 CI 含 1 且 mAP 几乎不动——量化误差极小，mAP 看不见 P_fa 变化。论文处理：表述为“统计不可区分，未见系统性恶化”，并以此为动机转向 E5 搬运主张（量化本身安全，但配置/校准集变化必须搬运）。

### E4 — 量化传播命题 P1｜合成（gauss + t3）

**协议**：n=1e6，对照 4 配置（线性逐张量 / 对数域 / 逐通道 / σ 层 FP16），判据“配置 2/3 相对配置 1 的 Δln P_fa 下降 ≥5×”。

**dln 缩放指数（Δln P_fa ~ ε^p）**：

| 配置 | gauss | t3 |
|---|---|---|
| linear_tensor | **1.955** | 1.543 |
| log_tensor | 2.037 | 1.024 |
| channel_linear | 2.033 | 1.054 |
| fp16（对照） | **≈0**（−1.23e-15） | — |

- gauss 下 linear_tensor 指数 1.96 ≈ 2，与 Prop.2 的“σ 项二次主导”一致；fp16 对照指数 ≈0（无量化误差），互为印证。
- **P1 严格判据（≥5× 下降）：未全过**（gauss drop_factor 0.067–1.85，多数 < 5）。
- **判定：P1_all = false**（审计负结果，如实报告）。

**论文处理**：报告“Δln~ε² 标度成立（gauss），但 P1 的 5× 改进判据不成立；t3 下指数偏离 2，σ 项主导论断需修正”。

### E5 — 阈值搬运（免数据跨配置）｜板级实测（**核心主张，最强证据**）

**协议**：整数阈值 λ_int 按 scale 比值搬运 `λ_new = round(λ_old · δ_s_old/δ_s_new)`，三列对照：搬运 / 重标定上界（64 图）/ 不换算。n_meas=949703，α=1e-3。

| FP16→INT8 旧 | — | — | — | 0.0078125 | 0.0078125 |
| FP16→INT8 新 | — | — | — | 0.000776221 | 0.0078125 |
| calmA（设置1 旧） | 0.000758752 | 0.00133807 | 0.000438232 | **0.000823526** | 0.0078125 |
| roughB（设置1 新） | 0.000675035 | 0.00122213 | 0.000399444 | **0.000737188** | 0.0078125 |

**设置 1：同设备换校准集 A→B（232 图）**

- 板上 mAP：calmA 0.9793（P=0.5804 R=0.9853）、roughB 0.9820（P=0.5684 R=0.9890）（量化无显著精度损失）。

> 这是“只有这类板子能做”的最强证据：GPU 的 scale 不是编译期常量，搬运规则在 GPU 上无处定义。

### E7 — 板级系统“误警→负载”耦合（C3）｜板级 dump

**部署矩阵 {FP16,INT8}×{全局模式（λ_glob，式 3.2a）, QCert 逐场景模式（λ(x)，式 3.2）}**——两列是同一契约的两个运行点（见论文 §3.1.1 双模式阈值），非两种方法；n_rough=77，功率 9.31 W：

| 配置 | cand P90(粗糙) | dec_ms | T_e2e 均值 ms | P99 ms | P99/mean | P_fa | J/艘 |
|---|---|---|---|---|---|---|---|
| FP16-全局 | 28.0 | 0.0239 | 45.524 | 45.526 | 1.00005 | 9.996e-4 | 0.332 |
| FP16-QCert | 9.0 | 0.0239 | 45.524 | 45.528 | 1.00008 | 1.071e-3 | 0.333 |
| INT8-全局 | 27.6 | 0.0241 | 34.704 | 34.706 | 1.00004 | 9.986e-4 | 0.220 |
| **INT8-QCert（本文）** | **9.0** | 0.0240 | 34.704 | 34.708 | 1.00009 | 1.071e-3 | 0.239 |

**判定**：

| 项 | FP16 | INT8 |
|---|---|---|
| 粗糙下 cand P90 比值 全局/QCert | **3.111×** | **3.067×** |
| pass_cand（≥2×） | ✓ | ✓ |
| pass_dec_ms（<3ms） | ✓ | ✓ |
| J/艘 drop | 0.997 | 0.921 |

**解读**：**逐场景模式**按每场景 1−α 分位标定 λ(x)，候选 ≈α·n_cell 逐场景恒定，把粗糙海况候选数 P90 从 ~28 压到 9（≈3.1×）；全局模式单一阈值只在混合池上保期望 P_fa，粗糙海况候选因此漂到 28——两列总 P_fa 同为 ≈α（1.00e-3 vs 1.07e-3）而候选差 3 倍，正是两运行点的分工证据，非矛盾。判决层 0.024 ms ≪ 3 ms（host-free 证据）；P99/mean≈1（时延几乎无尾）。注：E8/E9 的期望精度口径用全局模式（err 0.0185，见 E9 item5），负载口径用逐场景模式（本实验），不可读作同一配置同时取得两个数字。

### E9 — 标定方案消融｜真实（items 3/4/5）+ 合成（items 1/2/6/8）

**真实数据项（232 图，reps=10）**：

- **item3 块抽样 keep 比**：keep=1 → P_fa 1.590e-3（err 0.201，n_eff 49.8）；keep=0.0625 → P_fa 4.717e-3（err 0.674，n_eff 6.0）。keep 降 → 有效样本与精度同步恶化。
- **item4 标定样本量**：n=16/64/128 → 相对误差 mean 0.0886/0.0802/0.0757（n=128 最稳）；n=200 反升至 0.151（块抽样边界效应）。
- **item5 逐场景 vs 全局**：
  - P_fa：逐场景 1.590e-3 vs 全局 1.043e-3（全局更贴近 α=1e-3）；
  - **标定误差 err：全局 0.0185 ≪ 逐场景 0.2014**；
  - P_d：逐场景 0.1863 vs 全局 0.1828（Δ=0.0035，可忽略）；
  - **keep_per_scene = false → 采用全局阈值**。

**合成项**：item1 divfree/zquant 偏差 ≤1.4%（除法消除与零量化有效）；item2 B4096 达标；item8 round 指数 2.055≈2、floor 1.268（round 更符合二次标度）。

> 注：items 1/2/6/8 依赖 μ/σ 结构留合成版；item7 因 E2 阴性（板上饱和不随档上升）降权。

## 5. 论文主张 → 证据映射

1. **“整数阈值可跨量化配置/校准集搬运，无需重跑标定”**（核心创新 C1）：

   E7 粗糙海况候选数 P90 降 3.1×，判决层 0.024ms host-free。

5. **“量化误差界可解析预测”**：

## 6. 需在论文中如实处理的薄弱点

1. **E0 R 点判据 NO-GO**：R=0.969 略低于 1，CI 含 1。表述为“统计不可区分，未见系统性恶化”；不作为反例，而作为转向搬运主张的动机。
